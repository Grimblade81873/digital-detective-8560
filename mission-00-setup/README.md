## 3. Commands / Tools Used

| Command | Purpose |
|---------|---------|
| `python3 --version` | Check that Python 3 is installed — returned Python 3.13.15 |
| `git --version` | Check that Git is installed — returned git version 2.54.0 |
| `mkdir` | Create the project folder and all mission subfolders |
| `touch` | Create empty README.md files inside each mission folder |
| `git init` | Initialise a new Git repository in the project folder |
| `git add .` | Stage all created files for the first commit |
| `git commit -m "..."` | Save the staged files as the first commit |
| `git remote add origin` | Connect the local repo to the GitHub remote |
| `git push -u origin main` | Push the initial commit to GitHub |

## 4. My Understanding

A **repository** is like a project folder that Git tracks. Every change I make to files inside it gets recorded, so I can go back to earlier versions if needed. I organised the repository into separate mission folders so that each mission's work stays in its own place. This makes it easy for my instructor to find and review each mission individually. It also keeps things clean — I know exactly where to put my work for each task.
