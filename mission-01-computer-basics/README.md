## 4. My Understanding

### Task 1.1 — Trace One Activity Using IPOS

**Activity chosen:** Searching the internet for information.

| Stage | What Happens | Hardware / Component |
|-------|-------------|---------------------|
| **Input** | I type a search query using the keyboard and click the search button with the mouse. | Keyboard, mouse |
| **Processing** | The browser sends my query over the network. The search engine's servers process it and find matching results. My CPU handles running the browser and rendering the page. | CPU, RAM, network adapter |
| **Output** | The search results are displayed on my screen as a list of links and descriptions. | Monitor / display |
| **Storage** | The browser saves my search history and caches parts of the webpage on the SSD so pages load faster next time. | SSD (solid-state drive) |

The activity flows in a clear sequence: I provide input, the computer processes it, it shows me output, and it stores data for later use. Even a simple search involves all four stages.

## 5. Difficulties Faced

I had to think carefully about what counts as utility software versus application software. At first I thought antivirus would be application software, but it is actually utility software because its main job is to protect and maintain the system rather than help the user do a specific task like writing or browsing.

## 6. How I Resolved Them

I re-read the definitions from the assignment: operating system software manages the computer, application software helps users do tasks, and utility software maintains or protects the system. That cleared up the difference.
