## Running the Number Converter

The number converter program is located in `mission-05-numbers-data/number_converter.py`.

To run it:

```bash
cd mission-05-numbers-data
python3 number_converter.py
```

Enter any positive decimal number when prompted. The program will display its binary and hexadecimal equivalents.

## My Learning

Here are some of the key things I have learned while working through this assignment:

1. **The IPOS cycle is everywhere.** Every interaction with a computer — whether typing a document, browsing the web, or even using an ATM — follows the Input-Process-Output-Storage pattern. Understanding this helped me see computers as systems rather than just screens.

2. **The Terminal is powerful once you get used to it.** At first, typing commands felt slow compared to clicking around in Finder. But commands like pipes and flags let me do things much faster, like filtering long outputs or listing hidden files. I can see why developers prefer the command line for many tasks.

3. **Git is more than just saving files.** Before this assignment, I thought version control was just about backing up files. Now I understand that staging, committing, branching and Pull Requests create a structured workflow that makes it safe to experiment and collaborate without breaking things.
